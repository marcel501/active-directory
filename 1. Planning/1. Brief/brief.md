Active directory pathway project brief
=======================================

# INTRODUCTION

This project consists of an educative effort to methodologically develop an intuition and understanding of active directory services. The concepts of this useful technology must be based upon fundamental computing information as well as other domain specific information which this technology relies on.



___

# BACKGROUND

As an engineer the task is to develop an intuition and understanding of the active directory (AD) technologies, initiation, deployment and management. Before focused study on AD is initiated, thorough prerequisite knowledge in OS fundamentals, OS administration and server administration (especially windows server) must be supplied. 




___

# KEY FEATURES

- Have an understanding of OS backgrounds, its usage, elements, categories, types, and names of mainstream OSes in use
- Understand what a server is and how to effectively administrate devices and services
- Know how windows works as an OS and effectively administrate the windows server
- Explore the need of multi device administration & scalability
- Have knowledge in AD architecture and basic deployment
